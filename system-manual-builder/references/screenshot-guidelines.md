# 截图规范

- 默认保留原始截图，不脱敏、不裁剪关键上下文；用户明确要求时才脱敏，并保留原始文件。
- 截图显示页面标题、关键菜单/按钮和必要字段；加载遮罩、空白页、半加载状态不得作为功能截图。
- 点击后等待网络/动画稳定；地图、图表等待图层/图例完成。常见加载层包括 `.el-loading-mask`、`.el-loading-spinner`、`.loading`、`.ant-spin`。
- 列表、查询结果、详情、新增、编辑、审核、验收、统计、标签页、筛选、导入/导出、AI 分析等主要状态分别截图。
- 命名：`平台_子系统_序号_页面_动作.png`，不含账号、密码或令牌。图片下方写图号、页面、动作和状态。
