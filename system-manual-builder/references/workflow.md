# 系统遍历与编写流程

先记录 URL、账号角色、允许操作边界、已有 Word/截图和输出目录；账号密码不得写入手册、台账或截图文件名。

登录后回到驾驶舱/真实首页，逐个平台展开子系统、菜单、二级菜单、标签页和弹窗入口，登记路由、角色、可访问性、截图编号和章节。按列表、表单、审核/验收、图表/地图分别验证查询、重置、筛选、分页、详情、导出、新增/编辑字段、校验、附件、状态和联动。

只读验证优先；破坏性动作必须再次取得明确授权。页面完全加载且遮罩消失后截图，并立即在 `functions.csv` 登记页面、动作、文件名、按钮和结果。异常写入测试问题，不凭空补写。独立手册完成后用功能、流程和数据对象台账做覆盖检查，再生成整合版目录/索引。
