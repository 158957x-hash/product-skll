# Word 文档模板

独立手册：封面 → 文档信息/版本 → 目录 → 系统简介 → 范围与角色 → 登录与入口 → 按菜单/流程的详细操作 → 查询/导入导出/统计 → 审核实施验收和状态 → 异常 → 关联功能与数据流 → 附录（字段、按钮、截图索引、测试问题）。

整合版：封面 → 编制说明 → 平台总览 → 后台目录 → 小程序/H5 目录 → 功能索引 → 角色矩阵 → 关键流程 → 跨系统关系和数据对象 → 独立手册索引 → 未验证项；不复制独立手册完整步骤。

正文和表格统一微软雅黑或宋体；标题、目录、页码、页眉页脚、图片等需可交付。图片等比缩放、表头跨页重复，交付前确认 Word 可打开且图片不丢失。
